# Vinix Music 🎧

A Spotify-inspired Web Player built with React.js, featuring real-time audio visualization, synchronized lyrics, lossless FLAC streaming audio engine, and a dark glassmorphic UI.

## Features ✨

- **Modern Glassmorphic Dark UI**: Spotify-grade layout with responsive mobile and desktop experiences.
- **Cinematic Artist Discography**: Complete catalog of tracks and albums for South Indian music directors and indie sensations.
- **Live 3D Audio Visualizer**: WebAudio API frequency spectrum visualizer synced with playback.
- **Mobile Touch Optimized**: Horizontal swipeable carousels, compact cards, single-line track rows, and mini player.
- **Interactive Top Bar & Profile**: Hi-Res audio indicator, search, notifications dropdown, and account sign-out/sign-in.
- **Audio Controls**: Shuffle, repeat modes, queue management, volume control, and favorite tracks library.

## Getting Started 🚀

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Run

```bash
# Install dependencies
npm install

# Run locally in development mode
npm run dev

# Build for production
npm run build
```
